# Book Club Turn-taking

## Purpose

Fictional book club scenario for balancing discussion time.

## Setup

- Scenario ID: `community_book_club_turns`
- Domain: `academic_research`
- Category: `community`
- Agents: `agent_a` and `agent_b`, both synthetic fictional participants

## Event Focus

`community.book_checkpoint` records this checkpoint: The facilitator invites two shorter comments before moving on.

## Metric

`participation_balance` is a scenario-specific score for inspecting replay quality and interaction clarity.

## Safety

Ethics guardrail complete: fictional agents only, no real people, no forecasting, no scoring of suspects.
