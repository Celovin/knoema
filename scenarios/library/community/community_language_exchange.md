# Language Exchange Pairing

## Purpose

Fictional language exchange scenario for pairing participants.

## Setup

- Scenario ID: `community_language_exchange`
- Domain: `academic_research`
- Category: `community`
- Agents: `agent_a` and `agent_b`, both synthetic fictional participants

## Event Focus

`community.language_checkpoint` records this checkpoint: Organizers match participants by practice goals.

## Metric

`pair_fit` is a scenario-specific score for inspecting replay quality and interaction clarity.

## Safety

Ethics guardrail complete: fictional agents only, no real people, no forecasting, no scoring of suspects.
