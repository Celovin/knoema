## [Unreleased]

### Added — Round 6-9 commercial + ops surface
- `playground.ops_panel` + `playground.ops_app` — Operations admin Gradio app surfacing the round-6 commercial features. Four cards: precise tiktoken counter (with chars/4 heuristic side-by-side so Hangul under-counting is visible), tenant registry encryption-at-rest badge + sortable table, rate-limit health (backend type + non-destructive bucket probe), Stripe webhook inbox (configuration badge + dedup ring depth + registered handler types). Warm cream / ink / terracotta palette; every panel ships an empty state with operator-friendly copy. Standalone launcher on port 7861 by default; `share=False` enforced. 19 tests cover empty states, encrypted vs plaintext registry rendering, Korean token accounting divergence, rate-limit probe correctness, Stripe handler states, and defensive rendering when `registry.load()` raises.
- `luvoire.api.routes.stripe_webhook` — inbound Stripe webhook receiver. `POST /webhooks/stripe` reads the raw body bytes for signature verification (JSON re-serialisation breaks the HMAC), invokes `stripe.Webhook.construct_event` against `STRIPE_WEBHOOK_SECRET` with a 5-minute tolerance window, deduplicates on `event.id` via an LRU `OrderedDict` capped at 4096 entries, and dispatches to per-event-type handlers registered via `StripeWebhookHandler.register()`. A misbehaving handler is logged + swallowed so one broken event does not force Stripe into infinite retry. 503 when the secret is unset, 400 on missing/bad signature, 200 with `deduplicated` flag on success. 16 tests cover handler config, signature rejection, dedup correctness, dedup cap eviction, handler-exception swallow, and end-to-end route behaviour with a stubbed Stripe SDK.
- `luvoire.api.rate_limit.RedisRateLimitBackend` — atomic Redis-backed token bucket using a Lua `EVALSHA` script for read-modify-write, so multi-replica deploys cannot double-spend the bucket. Lua source registered once at backend construction; each `consume` is a single round-trip. Bucket TTL bounds Redis-side memory. `RateLimitBackend` Protocol; `RateLimiter` factory accepts either `_InMemoryBackend` (default) or `RedisRateLimitBackend(redis_client)`. 8 tests cover in-memory contract preservation, Redis success-within-burst, throttle on exhaustion, key namespacing, invalid TTL / empty prefix / missing `register_script` rejection, and Lua-script registration shape.
- `luvoire.billing.tenant_registry` Fernet encryption-at-rest — opt-in AES-128-CBC + HMAC-SHA256 via `cryptography.fernet`. Activated by `LUVOIRE_TENANT_REGISTRY_KEY` env or `encryption_key=` constructor kwarg. Magic prefix `luvoire-tenants-v1\n` lets `load()` auto-detect format, so a deploy can roll forward to encryption without breaking plaintext files already on disk. Save uses atomic temp-write + rename. The registry stores only Argon2 hashes (not raw secrets), so encryption is defense-in-depth. 7 tests cover plaintext fallback, encrypted round-trip, magic prefix, wrong-key rejection, missing-key error, plaintext-after-encrypted auto-detect, env pickup, and blank-env-treated-as-unset.
- `luvoire.llm.gateway.estimate_tokens` switched from `len(text) // 4` heuristic to `tiktoken` (`cl100k_base`) when the package is installed, with the heuristic as automatic fallback for air-gapped CI / minimal deployments. Lazy-loaded encoder cached after the first call. Korean / mixed-script prompts now bill realistically — Hangul codepoints encode to ~2-3 BPE tokens each rather than 1/4 of the character count. 6 new tests; the existing suite still passes against the heuristic when tiktoken is unavailable.
- `luvoire.llm.gateway.LLMGateway(fallback_deadline_seconds=120.0)` — cumulative deadline across the provider fallback loop. Without this, three slow providers each timing out at their own per-call timeout could turn one `complete()` into a 6-minute hang. Deadline check at the top of every iteration in both `_complete_live` and `_complete_with_replay_cache`. Raises `TimeoutError` with `last_error` chained for diagnostics. 3 tests cover deadline-aborts-remaining-providers, positive-only constructor, and default-present.
- `luvoire.llm.gateway._redact_secrets` — credential-pattern scrubber for `LLMCallRecord.error`. Provider exception messages can include the offending API key (`AuthenticationError: invalid key sk-proj-...`); without redaction those strings reach observability backends and log shippers verbatim. Patterns: OpenAI `sk-*`, Stripe `sk_(test|live)_*`, Luvoire `luvoire_ak*`, Bearer headers, Slack `xox[baprs]-*`. 7 tests cover known patterns, multi-credential messages, non-credential pass-through, and end-to-end redacted error storage.
- `luvoire.api.usage_middleware` payload validation — drops records with negative tokens / negative cost / token counts above 10M cap (well above any real provider response, well below 32-bit overflow), and malformed payloads. All drops emit a WARNING tagged with tenant id. Defense-in-depth against route-handler bugs or crafted payloads that would otherwise corrupt monthly tier-cap arithmetic.
- `luvoire.demography.kosis_fetch` HTTP response size cap — `max_response_bytes=10*1024*1024` constructor kwarg + Content-Length header pre-check before `response.content` access (so we abort BEFORE httpx buffers a malicious gigabyte stream). Defense-in-depth post-buffer check covers chunked-encoding endpoints that omit Content-Length.
- `luvoire.demography.kosis_fetch._read_cache` corrupted-cache auto-purge — deletes the offending file on JSON parse failure or non-object payload, so the next call falls through to refetch. Without this, a single corrupted cache entry would wedge `fetch_aggregate` forever. Uses `contextlib.suppress(OSError)` for the unlink itself so a locked / permission-denied file does not mask the original parse error.
- `luvoire.demography.synthesis.CellPopulation` arrays now read-only at the buffer level — `np.array(..., copy=True)` + `setflags(write=False)` so a caller cannot defeat the frozen-dataclass invariant via `cell.male[0] = 9999`. Caller's source array remains writeable (the copy is what gets locked).
- `luvoire.api.auth._tokens_equal` — constant-time API-key comparison helper for the legacy server-wide path. Replaces the previous `token != expected` (timing side-channel) with `secrets.compare_digest` over identical-length byte sequences. Missing token paths take the same fixed-length compare so response time does not vary with the length of `expected`. 6 tests cover match, mismatch, None inputs, length differences, and Unicode keys.
- `luvoire.billing.webhooks.verify_signature_with_window` — receiver-side helper that verifies HMAC AND rejects deliveries whose envelope `timestamp` falls outside a rolling window. `WebhookDispatcher.deliver_now` now embeds an integer `timestamp` field in every signed envelope (Stripe convention). `DEFAULT_REPLAY_WINDOW_SECONDS = 300`. Without this, a captured signed delivery could be replayed indefinitely. 7 new tests cover envelope timestamp shape, window accept/reject, wrong-secret, missing-timestamp, bool-timestamp rejection (Python's `isinstance(True, int)` quirk), and zero/negative window.
- `luvoire.billing.api_keys.rotate(key_id, grace_period=...)` — rotation grace period now configurable with a 1-hour default (was 24h hardcoded — too long when rotation is triggered by suspected leak). `timedelta(0)` for an immediate cut on known compromise. Audit log captures `grace_period_seconds` + `severity: high` so SOC pipelines can flag short-grace rotations as security events.
- `luvoire.demography.byod` NFC normalisation — `_normalise_column` and `_split_column_tokens` now apply `unicodedata.normalize("NFC", ...)` before token comparison. Without this, an NFD-decomposed Hangul column (e.g. `"이메일"` arriving as Jamo decomposition) silently bypassed the forbidden-token frozensets, which store NFC literals. 10 parametrised tests cover NFD variants of both individual and geometry tokens.
- `luvoire.demography.projector._as_float_array` rejects NaN / +-Inf at the array boundary. The pre-existing `(arr < 0).any()` guard is False for NaN, so a NaN-laden rate or population would propagate through the entire horizon undetected. 5 tests cover NaN/Inf in `CohortPopulation` counts and `DemographicRates` ASMR/ASFR/migration.
- `luvoire.demography.region.RegionLabel` admin_code prefix↔sido cross-validation. `_SIDO_BY_PREFIX` maps the 17 SGIS prefixes to their canonical sido string; `__post_init__` rejects mismatches like `RegionLabel(admin_code="26680", sido="서울특별시", ...)` (Busan prefix paired with Seoul sido). 4 new tests + a registry-wide invariant assertion.
- `luvoire.theory.rat.VERSION = "v1"` constant matching the canonical Tier A ref `code:luvoire.theory.rat.v1`.
- `scripts/lint_dsl_v2` Tier A code-ref import resolution — `importlib.import_module()` the dotted path behind every `code:<dotted.path>.vN` ref and cross-check the version suffix against `module.VERSION`. Catches typos (`ghost.v1`), version drift (`rat.v9` vs module v1), missing `VERSION` constants, and malformed ref shapes. 5 new tests.

### Added — earlier rounds
- `experiments/demographic_sensitivity/` — committed Sobol variance-decomposition sweep extending the RAT v1 sensitivity framework (`experiments/rat_sensitivity/`) to the demographic projector. Two scalar perturbations (`fertility_scale` and `mortality_scale`) over `[0.7, 1.3]` produce a year-30 total-population Sobol decomposition. `n=1024` base samples, `4096` model evaluations, seed `20260428`, deterministic SHA256 `b0841832b1f973d345dce7517ad4f0aba528dd8a54950c7293f171710c1baee4`. Mortality axis shows the canonical `S_T > S_1` inequality (first 0.7088, total 0.7931); fertility axis shows finite-sample noise at this `n` (well-documented limitation, robust at `n >= 32k`). Results committed in `results/sobol_indices.json` + `sobol_indices.md` + `run_manifest.json`. 8 new tests cover determinism, byte-identical re-run, manifest invariants, mortality `S_T > S_1`, finite-value sanity, and idempotent `main()`.
- `luvoire.demography.region` registry expanded from 4 시군구 to **31 시군구** covering all **17 시도** (서울특별시·부산광역시·대구광역시·인천광역시·광주광역시·대전광역시·울산광역시·세종특별자치시·경기도·강원특별자치도·충청북도·충청남도·전북특별자치도·전라남도·경상북도·경상남도·제주특별자치도). Strings only — admin_code (5-digit 행안부) + sido + sigungu, no coordinate / polygon / EPSG / geometry fields. New 강원·전북 특별자치도 명칭(2023-06-11 / 2024-01-18 변경) 사용, 구 ``강원도`` / ``전라북도`` 표기는 명시적으로 거부. 6 new tests cover 17-시도 coverage, admin-code uniqueness + 5-digit invariant, 시도별 sigungu floor, and registry size band.
- `luvoire.demography.report` — Public Safety Service Demand Projection (PSSDP) generator. `ServiceDemandCoefficients` carries per-1000 demand coefficients (fire/119 elderly-driven, school-age 6-18, patrol total). `project_service_demand()` is purely arithmetic over `CellPopulation`. `ServiceDemandReport` carries per-cell projections + per-scenario aggregate totals. `render_demand_panel()` writes a deterministic JSON panel with stable `panel_sha256`. Output is decision-support for municipal planning (학교 / 119 / 파출소 인프라 수요), not decision-system for LE; demand is projection (추계), not prediction (예측). 17 new tests pass.
- `luvoire.demography.kosis_fetch` — KOSIS aggregate fetch + local file cache layer with **optional online** semantics. `KosisFetchClient` SHA-256-keyed file cache, lazy `httpx.Client`, aggregate-only validator (rejects sub-시군구 동·읍·면 levels and below-floor populations). Offline cache miss raises `KosisFetchError`; engine remains importable on air-gapped CI without `base_url` / `api_key`. All HTTP traffic routes through `httpx` and may be intercepted via `httpx.MockTransport` from tests. 17 new tests pass; no real KOSIS API calls.
- `scenarios/seoul_demography_30y/run_pssdp_panel.py` and `results/demand_panel.json` — committed deterministic PSSDP demand panel built on top of the 30-year demographic scenario. Three KOSTAT-style fertility scenarios (low / medium / high) produce per-cell aggregate fire/119 + school-age + patrol demand projections; `panel_sha256` is invariant. Separate entry point so the existing `demography_summary.json` SHA stays unchanged. 3 new scenario tests verify panel determinism, 3-scenario coverage, and fertility ↔ school-age-demand monotonicity.
- `tests/test_demographic_kostat_reference.py` — 9 reference tests asserting our cohort-component projector's qualitative agreement with KOSTAT 장래인구추계 patterns: low ≤ medium ≤ high ordering preservation across 30 / 50-year horizons, baseline TFR 0.7 population decline, age-pyramid aging under low fertility, non-negative cohort clamp under extreme mortality scaling, and Tier A canonical reference lock for `code:luvoire.demography.cohort_component.v1`.
- `luvoire.demography.federated` — local-only federated-mode interface for sensitive BYOD demographic ingest. `LocalAggregator` protocol describes the caller-side aggregator contract (raw individual records never leave the caller's machine); `FederatedRequest` and `FederatedResponse` frozen dataclasses describe the aggregate message shape exchanged across the trust boundary. `run_federated_local_only()` is an in-process happy-path runner that loops a caller's `LocalAggregator` through the BYOD validator and optional DP noise layer. The interface is a deliberate **placeholder + contract**: we do not bundle a federated transport (gRPC, MPC, secure aggregation) — that is a downstream engineering choice. Civilian Use Policy alignment: the federated interface is not a face-saver, it merely relocates controller responsibility to the caller; aggregate output, no per-person, no sub-시군구 geometry guarantees still apply. 13 new tests pass.
- `luvoire.demography.dp` — differential privacy noise layer for aggregate demographic output. `DpBudget` carries `epsilon`, `delta`, and `sensitivity` with construction-time validation. `add_dp_noise()` applies calibrated Laplace (pure ε-DP, Theorem 3.6 of Dwork & Roth 2014) or Gaussian (`(ε, δ)`-DP, Theorem A.1, sigma = sensitivity * sqrt(2 * ln(1.25/delta)) / epsilon) noise under a fixed integer seed. Defaults clamp results to non-negative (post-processing of DP outputs is itself DP). `laplace_noise_scale()` and `gaussian_noise_sigma()` helpers exposed for diagnostic / reporting. The mechanism is fully deterministic under a fixed seed, preserving auditable replay while still satisfying the formal DP definition. 23 new tests pass.
- `luvoire.demography.byod` — opt-in aggregate-only BYOD (Bring-Your-Own-Data) validator. `validate_aggregate_byod()` and `assert_aggregate_byod()` enforce the aggregate-only / no-individual / no-real-geometry contract at ingest time: rejects individual-identifier columns (rrn, ssn, phone, email, passport, plate, imei, name tokens), rejects sub-시군구 geometry columns (lat, lon, epsg, geometry, polygon, wkt, h3, geohash, jibun, zip, postal), enforces `MIN_AGGREGATION_FLOOR` (default 10 000 — Korean 시군구 are ~5,000-1,500,000 residents so any sub-시군구 aggregate breaches it), validates 5-digit `admin_code`. Token-based whole-word matching avoids substring false positives such as `population` matching `lat`. 28 new tests pass.
- `scenarios/seoul_demography_30y/` — committed deterministic 30-year demographic projection scenario over a Seoul-style synthetic 5x5 grid (25 cells). Combines `luvoire.demography` cohort-component projection, `luvoire.demography.synthesis` Beckman-style cell allocation, and the locked `luvoire.theory.rat` v1 convergence rule. Three KOSTAT-style fertility scenarios (low / medium / high) produce parallel year-2056 trajectories; cell-level RAT distributions are compared. `scenario.yaml` carries `demographic_projection: true` + `pssdp_mode: true`. `run_scenario.py` produces a deterministic `results/demography_summary.json` with `summary_sha256` invariant. The `scripts/replay_equality_ci.py` gate now verifies 3 scenarios. 16 new tests cover DSL v2 load, ethics flags, KOSIS Tier B references, determinism, summary stability, output-shape policy invariants (no per-person key, integer cell counts, region-label-as-string).
- `luvoire.demography.synthesis` — Beckman-style multinomial cell-level population allocator. `CellPopulation` (synthetic cell id + age × sex aggregate counts) with regression test asserting no coordinate / polygon / EPSG / geometry attribute is exposed. `synthesize_cell_populations()` allocates a regional `CohortPopulation` across N synthetic-grid cells via Dirichlet-multinomial draws seeded for byte-identity. The aggregate-preservation invariant `aggregate(cells) == original.male, original.female` holds exactly (integer arithmetic). `cell_populations_total()` and `aggregate_cells_to_pyramid()` helpers round-trip cell tallies back to regional pyramids. Output is per-cell aggregate at the synthetic-grid floor — never individual records. 18 new tests pass.
- `luvoire.demography` subpackage — cohort-component demographic projector following the KOSTAT 장래인구추계 / UN World Population Prospects standard. Pure-numpy and fully deterministic. `CohortPopulation` (year × region-string × age × sex), `DemographicRates` (ASFR / ASMR / net migration / sex ratio at birth, with reproductive-age guard), and `CohortComponentProjector` (single-step + horizon projection with open-ended top class). `CounterfactualScenarioEngine` runs labelled `RatePerturbation` sets (`KOSTAT_REFERENCE_TRIPLE` low / medium / high fertility) for policy what-if comparison. `luvoire.demography.kosis` registers KOSIS aggregate-only metadata (출생/사망/이동/인구피라미드/장래추계, all KOGL Type 1, `시군구` aggregation floor enforced). `luvoire.demography.region` is a 시군구 **string-only** label registry — admin code + sido + sigungu, with a regression test asserting no coordinate / polygon / EPSG / geometry field is exposed; `ethics.no_real_geometry: true` remains intact. Output is **always aggregate** at registered region labels — no per-person, no sub-시군구 geometry, no individual prediction. Output trajectories are counterfactual scenarios (추계), not predictions (예측). 61 new tests pass.
- Scenario DSL v2 `EthicsSpecV2` gains two opt-in flags. `demographic_projection: bool = False` declares that the scenario uses `luvoire.demography` cohort-component projection over registered 시군구 string labels. `pssdp_mode: bool = False` declares Public Safety Service Demand Projection mode (학교 / 119 / 파출소 인프라 수요), positioning the scenario as decision-support rather than a decision-system. Validator interlocks: activating either flag while disabling `no_prediction` is rejected with a configuration-mistake error; activating `pssdp_mode` while disabling `no_suspect_scoring` is also rejected. The flags do **not** unlock prediction or suspect scoring — they only label aggregate demographic projection. 6 new ethics validator tests + 1 new schema test.

### Changed
- `luvoire.calibration.sbi_adapter.PosteriorHandle.sample` now validates that the upstream posterior returns a 2-D ``(n, dimension)`` array and raises `RuntimeError` with the offending shape on mismatch (was a silent reshape on 1-D output and no dimension check). Hardens the boundary against malformed mock or upstream posteriors.
- `luvoire.shock.catalog.Catalog` gains opt-in `duplicate_ids()` and `has_unique_ids()` query helpers. Existing `add()` semantics are unchanged: the catalogue still does not enforce uniqueness, but callers can now detect duplicates without iterating manually.

### Added
- `luvoire.scaling.city_scale` extended with an `aggregate` trace mode for large-N runs. `CityScaleTraceMode` literal, `CityScaleTickAggregate` frozen dataclass, and `sample_agent_count` config field let callers retain only per-tick aggregates plus a deterministic sample of full per-agent frames. New `city_scale_aggregate_output_hash`, `CityScaleResult.aggregates`, `frame_count_total`, `event_count_total`, `write_aggregate_jsonl`, and `write_aggregate_parquet` helpers expose the compact stream. `benchmarks/city_scale_100k.py` plus a committed `benchmarks/city_scale_100k_report.md` demonstrate a 100 000-agent × 100-tick aggregate proof on a 200×200 grid (single-shard, deterministic, no live LLM calls). 2 new scaling tests cover aggregate determinism and parquet export.
- `paper/rat_methodology/` — RAT methodology paper drafts. `kci_draft.md` is a Korean-language draft targeting KCI venues (target submission 2027-09); `ssci_draft.md` is an English-language draft targeting SSCI venues or arXiv preprint (target submission 2027-12); `methodology_section.md` is the canonical shared methods text reused by both. All three documents include explicit Civilian Use Policy alignment and disclaim prediction, per-person risk scoring, and operational deployment. 6 smoke tests verify keyword presence, citation set, and policy disclaimers.
- `scripts/run_id.py` and `scripts/replay_equality_ci.py` reproducibility infrastructure. `run_id.py` computes a deterministic SHA-256 over `(code_tree_sha, scenario_yaml_sha, seed, python_version, optional pip_freeze)` and exposes a CLI for embedding the run id into reports. `replay_equality_ci.py` re-runs the synthetic_seoul and crimemind_compare scenarios and asserts each `summary_sha256` matches the committed value, complementing the existing `verify_replay_shas.py` byte-level msgpack invariant. 10 tests cover code-tree determinism, env-hash canonicalisation, run-id divergence under seed/env changes, missing-source handling, and the CI smoke.
- `scenarios/crimemind_compare/` — patterns-level comparison harness for the CrimeMind (arXiv 2506.05981, June 2025) RAT-prompt agent design. Re-implements the three-slot prompt structure (motivation / exposure / guardian-gap) by rescaling RAT v1 inputs with three Tier C weights; runs three regimes (`equal_weights`, `motivation_heavy`, `guardian_heavy`) over a 6×6 synthetic grid. `compare.py` produces a deterministic `comparison_summary.json` with `summary_sha256` invariant. 8 tests cover DSL v2 load, Tier A/C invariants, determinism, committed-summary stability, regime ordering, threshold lock, and grid dimensions. No CrimeMind code or data is loaded; methodological reference only.
- `luvoire.memory.actr_weight` — ACT-R-inspired base-level activation helper (Anderson 2007). `base_level_activation()` computes `B_i = ln(Σ (t - t_j)^(-d))` over past use ages with `MINIMUM_AGE_SECONDS` floor; `actr_retention_weight()` squashes the activation through a logistic to fit Luvoire's existing `[0, 1]` decay-score expectations. Standalone helper — does not modify the locked `SharedDecayScheduler` or replay artifacts. 14 tests pass covering monotonicity, decay-exponent sensitivity, multi-use summation, age-floor singularity, and dataclass freezing.
- `luvoire.cognition` middleware extension — three new pure-deterministic helpers stacked on top of the existing Monologue + SocialLearner surface. `dual_process.route_decision` selects between Sys-1 habit and Sys-2 reflection based on weighted trigger signals. `attention.allocate_attention` performs salience-weighted seeded sampling under a per-tick budget so crowded scenes drop items deterministically. `bias.render_bias_prefix` composes a canonical-ordered bias-prefix string for 8 biases (availability, confirmation, anchoring, framing, hyperbolic discounting, loss aversion, status quo, representativeness) and emits a SHA-256 fingerprint for audit. None of the helpers invoke an LLM directly; callers compose them around their own LLM gateway. 26 new tests pass.
- `luvoire.pom` subpackage — Grimm Pattern-Oriented Modeling 3-gate validation. `Pattern` frozen dataclass with binned target distribution + sum-to-1.0 invariant. Three canonical reference factories: `time_of_day_pattern` (G1), `activity_diversity_pattern` (G2), `hotspot_distribution_pattern` (G3, structural only — never real). `evaluate_gate` and `evaluate_three_gates` compute discrete KS distance against the pattern's target CDF; threshold-based pass/fail. `score_pom` produces a weighted composite score in [0, 1] (higher better). Pure numpy + stdlib (no scipy dep). 35 tests pass.
- `luvoire.calibration` subpackage — simulation-based-inference + sweep + scenario-discovery adapters with **lazy-imported optional deps** (`sbi`, `optuna`, `ema_workbench`). Each adapter raises a typed `*Unavailable(RuntimeError)` when the optional package is absent so the engine installs without them. `RejectionAbcSpec` + `rejection_abc` ship a pure-numpy fallback ABC sampler that is byte-deterministic per seed. Frozen dataclasses with `slots=True` mirror the `luvoire.sensitivity.sobol` style. 36 tests pass + 3 skip (importorskip for real-package smokes).
- `luvoire.shock` subpackage — exogenous synthetic-shock catalogue overlaying time-and-space modifiers on the synthetic urban grid. Five `ShockKind` literals: festival / protest / policy_change / weather_event / infrastructure_change. `Catalog` is immutable (`add()` returns a new tuple-backed instance); `active_at(tick)` and `affecting(cell_id, tick=None)` filter by inclusive window and cell membership. `ShockScheduler` applies catalog effects to RAT v1 inputs: `apply_to_target` and `apply_to_guardianship` clamp to [0, 1].
