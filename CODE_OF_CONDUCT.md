# Code of Conduct

Knoema Engine is an early research and engineering project. Contributors are expected to keep collaboration professional, specific, and respectful.

## Expected Behavior

- Use clear technical language and assume good faith.
- Keep discussions focused on the work.
- Respect privacy and avoid sharing sensitive or identifying data.
- Be precise when discussing safety, public-safety research, and limitations.
- Accept maintainers' decisions on scope, licensing, and repository hygiene.

## Unacceptable Behavior

- Harassment, threats, discrimination, or personal attacks.
- Publishing private information without consent.
- Submitting real sensitive incident data to examples, tests, issues, or pull requests.
- Making unsupported claims that the project predicts crime or identifies suspects.
- Introducing code or assets with incompatible licensing.

## Reporting

Report concerns to `hello@celovin.com`. Maintainers may edit, reject, or remove contributions that violate this code of conduct or the project safety boundary.
