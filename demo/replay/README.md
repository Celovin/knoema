# Offline Replay Demo

This directory contains deterministic, offline playback artifacts for the city-scale Gangnam-style replay.

- `viewer.html` opens directly as a static HTML viewer and loads local msgpack replay files.
- `generate_replay.py` regenerates the msgpack files with byte-identical output for the same seed.
- `scenario_config.yaml` is the single source of truth for the replay topology and role distribution.
- `profiles/ETHICS.md` defines the archetype-tier policy and the pedagogical-use disclaimer.

The profile overlays are teaching aids only. They are not operational profiles, predictions, or guidance for identifying any real person.
