# Concordia Reference

Concordia is treated as an external academic reference system, not a bundled baseline.

This repository does not vendor Concordia code and does not report Concordia performance numbers. To compare against Concordia, run an equivalent scenario in a separate environment, record the exact commit, dependency versions, model provider, prompt policy, and seed, then add the external result as a separate appendix.

Reference link: https://github.com/google-deepmind/concordia
