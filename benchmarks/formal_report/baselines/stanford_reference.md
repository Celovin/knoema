# Stanford Generative Agents Reference

Stanford Generative Agents is treated as an external academic reference system, not a bundled benchmark baseline.

This repository does not vendor the Stanford implementation and does not claim measured Stanford performance numbers inside the formal report. The public comparison point is the paper's 25-agent sandbox and the companion code repository. The cited public materials also do not provide a Sally-Anne score or a persona opt-in theory-of-mind API that can be claimed as equivalent. To compare against Stanford-style behavior, run an equivalent scenario in a separate environment, record the exact commit, dependency versions, model provider, prompt policy, and seed, then attach the result as a clearly labeled external appendix.
