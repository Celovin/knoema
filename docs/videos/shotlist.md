# Demo Video Shot List

Use this common shot list for the 30-second, 3-minute, and 10-minute recordings.

## Required Shots

| Shot | Surface | Purpose |
| --- | --- | --- |
| S01 | GitHub README top | Establish public repo, CI, license, Playground badge. |
| S02 | README architecture diagram | Show the core engine modules and data flow. |
| S03 | Playground scenario selector | Show no-key replay and live-model options. |
| S04 | Playground timeline | Show tick-by-tick agent actions. |
| S05 | Playground relationship graph | Show directed relationship state. |
| S06 | JSONL log preview | Show reproducible export and audit trail. |
| S07 | CLI terminal run | Show command-line reproducibility. |
| S08 | Dashboard playback | Show offline analysis workflow. |
| S09 | Godot adapter README | Show one game-engine integration path. |
| S10 | Unity adapter README | Show Package Manager install path. |
| S11 | Competitor matrix | Show positioning evidence. |
| S12 | Test command output | Show current verification state. |

## OBS Setup

- Canvas: 1920x1080.
- Output: 1920x1080, 60 fps.
- Browser zoom: 100%.
- Terminal font: 16-18 px.
- Cursor: visible.
- Audio: close mic, noise suppression on, no desktop notification sounds.

## Privacy Checklist

- Close private planning documents before recording.
- Do not show API keys, local tokens, cookies, or browser password prompts.
- Use replay-only mode for public footage.
- Keep all example scenarios fictional and synthetic.
