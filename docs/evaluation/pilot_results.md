# Pilot Results

The committed Phase 58 pilot is an internal protocol check using synthetic trace labels only. It is not a customer study, not a product claim, and not evidence of real-world behavior.

## Sample

| Field | Value |
| --- | --- |
| Raters | 5 |
| Pairs | 6 |
| Labels | left, right, tie |
| Template | pairwise preference |
| Purpose | verify export format and reliability calculations |

## Reliability

| Metric | Value |
| --- | ---: |
| Average pairwise Cohen kappa | 0.665 |
| Fleiss kappa | 0.665 |
| Pilot gate | pass |

## Notes

- Agreement is intentionally high enough to exercise the pass path.
- The sample is too small for publication claims.
- Low-agreement items in a larger run should be reviewed for ambiguous trace wording.
- Future external studies should record recruitment source, compensation, consent, and exclusion criteria before launch.
