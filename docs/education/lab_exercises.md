# Lab Exercises

Each lab is designed for a 30-minute classroom or recitation slot.

## Lab 1 - Install and Run

Run `luvoire run examples\cli_dorm.yaml --json`, inspect the JSONL output, and identify tick, agent, and action fields.

## Lab 2 - Scenario DSL Validation

Edit a safe Scenario DSL file, run `luvoire validate`, and fix every validation issue.

## Lab 3 - Trait Perturbation

Change one trait by 0.3, rerun the scenario, and compare action counts.

## Lab 4 - Event Injection

Add a scheduled event and explain which agents observe it.

## Lab 5 - Relationship Edge Reading

Use the Playground relationship graph to identify the strongest directed edge.

## Lab 6 - Memory Probe

Ask which prior event influenced an action and map the answer to JSONL rows.

## Lab 7 - Batch Mode

Run at least five seeds and export the CSV bundle.

## Lab 8 - Fairness Heatmap

Inspect trait-action effect sizes and write one paragraph on confounding risk.

## Lab 9 - Reproducibility Certificate

Export a run certificate and verify it against the result JSONL.

## Lab 10 - Presentation Dry Run

Use `?mode=present`, rehearse a three-minute walkthrough, and record the artifact paths.
