# Course Rubric

Use this rubric for the final project and adapt the same weights for major assignments.

| Area | Weight | Criteria |
|---|---:|---|
| Code and scenario implementation | 30% | Valid Scenario DSL, reproducible run scripts, readable configuration, and clear use of Luvoire APIs. |
| Written report | 40% | Research question, methods, evidence, analysis, limitations, and safety discussion are coherent and defensible. |
| Presentation | 20% | Demo clarity, explanation of results, response to questions, and visual communication. |
| Reproducibility | 10% | Run fingerprint, source config, JSONL logs, exported tables, and environment notes are attached. |

## Minimum Evidence

- Source YAML or Python config.
- JSONL run logs.
- Reproducibility certificate or replication package.
- One quantitative summary table or figure.
- A limitations section that separates observed behavior from claims about real people.

## Late and Safety Policy

Unsafe operational claims, real-person profiling, or attempts to bypass safety checks receive no credit for the affected section. Late work can be accepted only when the replication package still runs without instructor intervention.
