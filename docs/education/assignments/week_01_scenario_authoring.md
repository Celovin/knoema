# Week 01 - Scenario Authoring

## Learning Goal

Create and run a small safe Scenario DSL file.

## Task

Start from a two-agent scenario, change the setting, add one event, and validate the YAML.

## Deliverables

- Scenario YAML.
- JSONL output from a local run.
- 500-word note describing the scenario boundary and expected behavior.

## Grading

- 30% valid configuration and command transcript.
- 40% clarity of scenario design.
- 20% interpretation of JSONL rows.
- 10% reproducibility notes.
