# Week 12 - Final Project Presentation

## Learning Goal

Present a replication-ready simulation study with clear limitations.

## Task

Deliver an eight-minute presentation and submit the final artifact packet.

## Deliverables

- Slides using the course reveal.js template or equivalent.
- Final report.
- Scenario config, JSONL logs, and reproducibility certificate.
- Exported table or figure.

## Grading

- 30% implementation quality.
- 40% written report quality.
- 20% presentation quality.
- 10% reproducibility packet.
