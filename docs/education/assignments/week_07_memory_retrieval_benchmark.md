# Week 07 - Memory Retrieval Benchmark

## Learning Goal

Test whether retrieved memory evidence aligns with later actions.

## Task

Create a scenario where one early event should matter later. Inspect memory retrieval and action output.

## Deliverables

- Scenario config.
- Memory inspector excerpt.
- JSONL rows linking the early event to a later action.
- 800-word benchmark note.

## Grading

- 30% benchmark design.
- 40% memory-action evidence.
- 20% explanation of retrieval limits.
- 10% reproducibility packet.
