# Week 11 - Final Project Proposal

## Learning Goal

Freeze a final research question before running the final study.

## Task

Write a preregistration-style proposal for a final Luvoire experiment.

## Deliverables

- Research question and hypotheses.
- Scenario and trait design.
- Planned sample size or seed count.
- Analysis plan and replication checklist.

## Grading

- 30% design specificity.
- 40% analysis plan.
- 20% feasibility.
- 10% reproducibility checklist.
