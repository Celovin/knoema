# Week 04 - Events and Routines

## Learning Goal

Use events and routines to shape context without changing personality traits.

## Task

Add two scheduled events and one routine conflict to a scenario.

## Deliverables

- Scenario config.
- Timeline excerpt identifying event-triggered actions.
- One paragraph on why context is not the same as personality.

## Grading

- 30% event and routine correctness.
- 40% timeline analysis.
- 20% conceptual separation.
- 10% clean artifacts.
