# Week 06 - Relationship Analysis

## Learning Goal

Interpret relationship edges and conversation threads.

## Task

Run a scenario with at least three directed social actions and inspect relationship graph changes.

## Deliverables

- Relationship graph screenshot.
- Conversation thread excerpt.
- Short report identifying one strong edge and one ambiguous edge.

## Grading

- 30% valid run and graph capture.
- 40% edge interpretation.
- 20% thread evidence.
- 10% limitations.
