# Week 08 - Batch Statistics

## Learning Goal

Summarize variation across seeds rather than relying on one run.

## Task

Run at least ten seeds in batch mode and export statistical tables.

## Deliverables

- Batch JSONL.
- CSV bundle.
- One figure or LaTeX table.
- 700-word results note.

## Grading

- 30% batch setup.
- 40% statistical interpretation.
- 20% exported table or figure quality.
- 10% reproducibility notes.
