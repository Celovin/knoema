# Week 03 - Trait Slider Experiment

## Learning Goal

Isolate one trait manipulation and measure action changes.

## Task

Run a baseline and a treatment where one trait changes by at least 0.3 while the scenario stays fixed.

## Deliverables

- Baseline and treatment configs.
- JSONL logs for both runs.
- One table comparing action counts.
- 700-word interpretation with limitations.

## Grading

- 30% controlled manipulation.
- 40% evidence and interpretation.
- 20% table accuracy.
- 10% reproducibility notes.
