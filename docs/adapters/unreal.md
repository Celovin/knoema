# Unreal Engine 5 Adapter

The Unreal adapter is a source plugin scaffold for Unreal Engine 5.3 and newer. It keeps the engine-facing layer small by treating the Python API server as the simulation authority and the Unreal project as the presentation and control surface. `UKnoemaClient` wraps the Phase 44 REST API endpoints for simulation creation, status polling, and event injection. `UNPCAgentComponent` gives an Actor or Character a polling loop that can create a simulation on begin play, store the active simulation id, and push structured gameplay events back into Knoema.

Install the plugin into either `<Project>\Plugins\KnoemaUnreal` for project-local builds or `C:\Program Files\Epic Games\UE_5.3\Engine\Plugins\Marketplace\KnoemaUnreal` for a launcher-managed engine install. After enabling the plugin, create a Blueprint actor named `BP_BasicNPC`, attach `NPCAgentComponent`, and paste a valid `POST /simulations` JSON payload into `BootstrapSimulationJson`. The checked-in `.uasset` file is intentionally a placeholder note so this repository stays text-reviewable until a binary asset handoff is needed.

The adapter expects the Phase 44 API server to be reachable at `http://127.0.0.1:8000` by default. If `KNOEMA_API_KEY` is enabled on the server, set the matching bearer token in the component or client config before play. Blueprint logic can call `StartScenario`, `InjectWorldEvent`, and `GetSimulationState` without binding directly to HTTP code.
