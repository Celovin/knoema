# Group Polarization Dynamics

## Research Question

Do homogeneous value clusters polarize faster than mixed-value groups in repeated multi-agent interactions?

## Hypotheses

- H1. Homogeneous value clusters will polarize faster than mixed-value clusters.
- H2. Higher binding-morals profiles will increase within-group alignment and between-group distance.

## IV/DV

- IV: value composition, stressor intensity, group assignment.
- DV: between-group relationship distance, action distribution divergence, language alignment.

## Sample Size

Use at least 160 seed-condition observations. Run the Playground power analysis with an independent t-test, effect size 0.45, alpha 0.05, and target power 0.85.

## Analysis Plan

Use chi-square tests for action distribution shifts and t-tests for relationship distance effects. Report modularity and trust-distance summaries.

## Submission Checklist

- Group labels and value profiles are frozen before generation.
- Matched seed schedules are used across all conditions.
- Representative traces are anonymized before sharing.
