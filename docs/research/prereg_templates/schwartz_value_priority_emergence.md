# Schwartz Value Priority Emergence

## Research Question

Do Schwartz value priorities emerge as stable action preferences in repeated social interactions?

## Hypotheses

- H1. Self-direction and universalism will predict exploration and bridge-building actions.
- H2. Security and conformity will predict rule-following and risk-avoidant actions.

## IV/DV

- IV: Schwartz value priority band and scenario family.
- DV: value-consistent action rate, relationship centrality, trust accumulation.

## Sample Size

Use at least 144 agent-seed observations. Run the Playground power analysis with an independent t-test, effect size 0.45, alpha 0.05, and target power 0.80.

## Analysis Plan

Use regression over predeclared value bands and report standardized coefficients with confidence intervals.

## Submission Checklist

- Value profile assignments are frozen before running.
- Affinity labels for each action type are documented.
- Scenario-level caveats are included in the report.
