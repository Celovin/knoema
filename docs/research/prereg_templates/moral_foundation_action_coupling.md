# Moral Foundation x Action Coupling

## Research Question

Which moral-foundation trait bands predict action choices under contested-resource scenarios?

## Hypotheses

- H1. Higher care/harm scores will increase support and de-escalation actions.
- H2. Higher fairness scores will increase norm-enforcement actions when resources are contested.

## IV/DV

- IV: care/harm band, fairness band, resource pressure level.
- DV: moral-consistent action probability, target selection, relationship repair.

## Sample Size

Use at least 180 event-level observations after seed aggregation. Run the Playground power analysis with a two-proportion test, effect size 0.30, alpha 0.05, and target power 0.85.

## Analysis Plan

Apply trait-action chi-square tests with Benjamini-Hochberg correction. Report Cohen's w and top bias signals.

## Submission Checklist

- Resource-conflict events and action vocabulary are frozen.
- Trait band thresholds are declared before analysis.
- Heatmap output and JSONL digest are attached.
