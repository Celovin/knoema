# Conversation Coordination Patterns

## Research Question

Which trait profiles and bridge-agent conditions improve coordination in conversation-heavy social scenarios?

## Hypotheses

- H1. Higher agreeableness and conscientiousness will increase turn-taking regularity.
- H2. Stressor events will reduce coordination unless a high-trust bridge agent is present.

## IV/DV

- IV: bridge-agent presence, stressor condition, trait profile band.
- DV: turn-taking regularity, topic repair, response latency proxy, trust delta.

## Sample Size

Use at least 150 seed-condition observations. Run the Playground power analysis with an independent t-test, effect size 0.40, alpha 0.05, and target power 0.80.

## Analysis Plan

Use seed-level conversation-thread metrics and representative anonymized traces. Report entropy and topic repair rates.

## Submission Checklist

- Bridge-agent assignment and event injections are frozen.
- Conversation-thread metrics are computed before reading qualitative traces.
- JSONL digest and anonymized examples are attached.
