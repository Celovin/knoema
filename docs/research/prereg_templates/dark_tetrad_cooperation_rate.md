# Dark Tetrad x Cooperation Rate

## Research Question

How do Dark Tetrad trait profiles affect cooperation rates in fictional, safety-gated simulation scenarios?

## Hypotheses

- H1. Higher Machiavellianism and psychopathy profiles will reduce cooperation under resource stress.
- H2. IRB-gated fictional scenarios will show stronger effects than neutral classroom scenarios.

## IV/DV

- IV: Dark Tetrad profile band, scenario sensitivity class, resource stress.
- DV: cooperation rate, threat/refusal actions, target concentration, trust loss.

## Sample Size

Use at least 180 seed-condition observations. Run the Playground power analysis with a two-proportion test, effect size 0.30, alpha 0.05, and target power 0.85.

## Analysis Plan

Use two-proportion tests with Benjamini-Hochberg correction. Report safety caveats before substantive interpretation.
