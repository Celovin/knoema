# Roadmap

Knoema is an early MVP. The current roadmap keeps three tracks aligned.

## Game Track

- Improve SDK ergonomics.
- Deepen Godot and Unity adapters.
- Add richer NPC response contracts.
- Expand deterministic game examples.

## Research Track

- Strengthen reproducibility reports.
- Add cleaner external baseline comparisons.
- Expand scenario DSL validation.
- Improve dashboard analysis surfaces.

## Public Project Track

- Publish docs site.
- Improve website and Playground.
- Maintain Release Please PRs and tag-gated PyPI Trusted Publishing.
- Prepare academic and community launch materials.
