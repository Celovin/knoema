# Knoema Bench

Knoema Bench is a public seven-axis leaderboard for persistent-agent
simulation frameworks. It covers long-term memory, multi-layer retention,
symbolic theory-of-mind checks, hierarchical planning, and latency envelopes.

The leaderboard is intentionally conservative: every row must include a source
and a caveat for each axis, and external frameworks should mark comparison
slots as not measured unless they have actually run a comparable harness.
