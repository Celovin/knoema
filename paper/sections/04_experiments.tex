\section{Experiments and Evidence}

Knoema's Phase 30 evidence is engineering-oriented. The experiments answer whether the runtime can generate reproducible artifacts, whether the memory policy improves deterministic proxy metrics over a naive full-context baseline, and whether a 50-agent scenario can be committed and replayed as a public artifact.

\subsection{50-Agent Village Experiment}

The 50-agent village experiment runs a deterministic week with 50 synthetic agents, 42 ticks, and 2,100 committed actions. Each agent contributes 42 actions. The run records 100 relationship edges, a deterministic seed of 20260418, a bit-for-bit artifact check, and zero provider cost because it uses local deterministic decisions.

\subsection{500-Agent Metropolis Experiment}

Phase 42 extends the scale envelope with a deterministic metropolis rush-hour experiment. The run uses 500 synthetic agents, 20 fixed seeds, six 30-minute ticks per seed, and 60,000 total committed actions. The committed summary reports 1,657.527 mean actions per second, 65.055 ms mean p95 latency, 431.725 MB mean peak memory, and 5,000 relationship edges. The seed manifest, config fingerprint, JSONL hash, summary JSON, representative log, and latency/memory SVG are all committed so the scale claim is tied to concrete artifacts rather than an unversioned benchmark note.

\subsection{1000-Agent Distributed City Experiment}

Phase 52 extends the deterministic scale evidence to a 1000-agent city envelope with five location shards and 200 ticks. The experiment records three backend rows: single-process, process-pool with eight workers, and a Ray-compatible sixteen-worker row. Ray remains an optional dependency, so environments without Ray still regenerate the same committed envelope while marking Ray availability explicitly. The current committed summary reports 1,250.000 actions per second for single-process execution and 5,300.000 actions per second for the Ray-compatible row, clearing the 3x throughput gate while keeping memory at 1.050 MB per agent. The formal benchmark bundle imports the JSON summary and SVG throughput figure so the scale comparison remains tied to reproducible repository artifacts.

\subsection{Formal Benchmark Bundle}

The formal benchmark bundle runs four scenarios across two approaches and three local model profiles, producing 24 deterministic runs. The scenarios measure memory recall, relationship dynamics, narrative branching, and scalability. The comparison baseline is a naive full-context prompt policy. Mesa and Concordia are documented as external references rather than misrepresented as exact reimplementations.

\subsection{Theory-of-Mind Harness}

Phase 43 adds a persona opt-in theory-of-mind module and a deterministic Sally-Anne harness. The harness covers 20 structured cases that alternate between false-belief and witnessed-move conditions. Knoema reproduces the expected search location in 20 out of 20 cases, for an accuracy of 1.000 against a target gate of 0.800. This is a symbolic engineering check, not a claim of human-like social cognition.

\subsection{Classic ABM Reproductions}

Phase 45 adds two compact reproductions drawn from classical agent-based modeling literature. The Schelling experiment uses a deterministic 50x50 grid with 2,000 agents and a block-based neighborhood dissimilarity index. The deterministic run lands at 0.548 for a 0.3 similarity threshold and 0.942 for a 0.7 threshold, preserving the expected medium- versus high-segregation contrast. The Axelrod tournament runs 10 strategies for 200 rounds per pairing, with strategy profiles documented as personality-annotated prompt routes rather than hidden heuristics. In deterministic mode, Tit-for-Tat ranks first and remains inside the top three cooperative strategies across all labeled runtime surfaces.

\subsection{Evaluation Metrics}

Phase 46 adds two lightweight behavioral scoring functions so committed JSONL artifacts can be graded without re-running the simulator. Persona Consistency Score (PCS) summarizes whether one agent keeps a stable action mix, location pattern, normalized content signature, and target focus across a run. The current implementation uses
$\mathrm{PCS} = 0.25A + 0.25L + 0.30C + 0.20T$,
where $A$ is action recurrence, $L$ is location stability, $C$ is normalized content stability, and $T$ is target focus.

Relationship Coherence Score (RCS) summarizes whether interactions between two agents remain mutually directed, location-consistent, action-consistent, and dense enough to form a stable edge rather than a single accidental contact. The current implementation uses
$\mathrm{RCS} = 0.35R + 0.25L + 0.20A + 0.20D$,
where $R$ is reciprocal interaction coverage, $L$ is pairwise location alignment, $A$ is action alignment, and $D$ is interaction density.

The committed Phase 46 artifacts compute PCS over the 50-agent village log and RCS over a representative log from the 500-agent metropolis benchmark. The current scores clear the acceptance gates of PCS $\geq 0.75$ and RCS $\geq 0.70$, giving the report a compact, reproducible quality layer above throughput-only evidence.
