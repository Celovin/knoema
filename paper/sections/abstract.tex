\begin{abstract}
Luvoire is an early-stage Python runtime for LLM-based multi-agent social simulation. It combines persona prompts, hierarchical memory, directed social relationships, environment context, PAD emotion state, LLM-backed decision generation, and replayable logs behind a compact API. The MVP demonstrates one shared runtime across three domains: persistent-memory game NPCs, fictional public-safety scenario replay, and reproducible academic social simulation. This report describes the system architecture, safety boundary, and initial demonstration results from three executable notebooks plus a Streamlit dashboard and Godot adapter scaffold. The public-safety track is strictly framed as synthetic replay research, not prediction, suspect scoring, or operational decision automation.
\end{abstract}
