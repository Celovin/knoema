\section{Related Work}

\textbf{Generative agents and social simulation.} Generative Agents introduced believable language-mediated behavior through memory, reflection, planning, and interaction \cite{park2023generative}. Concordia frames generative agent-based modeling as grounded interaction among entities in physical, social, or digital spaces \cite{vezhnevets2023concordia}. The Sally-Anne false-belief task remains a compact behavioral probe for explicit theory-of-mind reasoning \cite{wimmer1983belief,baroncohen1985does}. Knoema shares the assumption that memory and context matter, but focuses on a compact runtime with explicit state objects, deterministic logs, adapter contracts, and a persona opt-in theory-of-mind surface.

\textbf{Multi-agent LLM frameworks.} AutoGen, CAMEL, MetaGPT, ChatDev, Voyager, Reflexion, ReAct, Toolformer, BabyAGI-style task loops, LangChain, LangGraph, CrewAI, Semantic Kernel, OpenAI Swarm-style handoffs, and tool-augmented agent benchmarks explore ways to coordinate LLM behavior through roles, tools, self-reflection, graph execution, or conversational protocols \cite{wu2023autogen,li2023camel,hong2023metagpt,qian2023chatdev,wang2023voyager,shinn2023reflexion,yao2023react,schick2023toolformer,liu2023agentbench}. Knoema is narrower. It is not optimized for task completion across arbitrary tools; it is organized around replayable social state and game/research integration.

\textbf{Classical agent-based modeling.} Mesa, NetLogo, MASON, Repast, Swarm, GAMA, AnyLogic, Sugarscape, Schelling segregation, Axelrod cooperation, ODD model documentation, and discrete-event simulation practice represent a long tradition of explicit model state, scheduling, and reproducible simulation loops \cite{terhoeven2025mesa,wilensky1999netlogo,luke2005mason,north2013complex,daniels1999swarm,taillandier2019gama,borshchev2013anylogic,epstein1996growing,schelling1971dynamic,axelrod1984evolution,grimm2006standard,law2014simulation}. Knoema borrows the inspectable-loop discipline from this tradition while adding natural-language memory and model-backed decision generation.

\textbf{Memory and retrieval.} Retrieval-augmented generation, dense passage retrieval, approximate nearest-neighbor indexes, and vector stores provide the retrieval substrate for long-term agent context \cite{lewis2020rag,karpukhin2020dpr,johnson2017faiss,malkov2020hnswlib,guo2020scann}. Knoema currently uses deterministic hash embeddings in tests and examples to keep local runs reproducible. Production deployments can replace the encoder while keeping the store API.

\textbf{Reproducibility and model risk.} Reproducible computational research depends on fixed configuration, versioned artifacts, and clear claims \cite{sandve2013tenrules,wilkinson2016fair,peng2011reproducible,pineau2021improving}. LLM-based systems add risks around prompt sensitivity, privacy, hallucination, and data contamination \cite{bommasani2021foundation,weidinger2021ethical,bender2021stochastic,mitchell2019modelcards,gebru2021datasheets}. Knoema therefore treats logs, synthetic data boundaries, and deterministic local paths as first-class engineering requirements.
