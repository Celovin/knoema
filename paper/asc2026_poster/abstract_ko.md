# ASC 2026 방법론 포스터 초록 (한국어)

**제목**: 합성 한국형 도시격자 ABM에서의 일상활동이론 — 감사 가능한 시나리오를 위한 결정성 리플레이

**투고처**: ASC 2026 Annual Meeting, Chicago IL, 2026-11-18 ~ 2026-11-21
**투고 마감**: 2026-05-15

## 초록 (한국어, ≤ 600자)

**배경.** 일상활동이론(RAT)은 동기화된 행위자, 적합한 표적, 유능한 보호자의 부재가 시공간에서 수렴할 때 범죄 기회가 발생한다고 본다. RAT를 투명한 에이전트 기반 모형(ABM)으로 옮길 때 흔히 수렴 규칙은 코드 깊숙이 묻히고 숫자 knob만 외부에 노출되어, 어떤 주장이 이론적이고 어떤 것이 실증적이며 어떤 것이 탐색적인지 평가자가 구분하기 어렵다.

**방법.** 본 연구는 RAT 수렴 규칙을 코드 상수로 잠그고 시나리오 YAML에서는 타입드 문자열(Tier A)로만 참조하도록 한 결정성 Python ABM을 제안한다. 실증 prior(Tier B)는 출처 메타데이터를, 탐색 knob(Tier C)는 범위와 기본값을 의무로 선언한다. 시나리오 DSL의 윤리 블록은 ``no_real_geometry: true``를 기본값으로 두며, 합성이 아닌 좌표계 라벨은 검증 단계에서 거부된다. 모든 실행은 시나리오 YAML, 코드 트리, 시드의 컨텐츠 해시로 식별되며, 5건의 SHA-256 invariant 테이블이 push마다 재검증된다.

**결과.** 4096-샘플 Saltelli 설계(20 480 평가, seed = 20260427)에서 RAT 세 요소의 Sobol 지표는 거의 대칭(1차 ≈ 0.23, 총 차수 ≈ 0.54)이며, 총 차수와 1차 차이는 출력 분산의 약 30%가 상호작용 효과임을 보인다 — 곱셈형 수렴 규칙의 이론적 예측과 일치한다. 동일 시드 실행은 로컬과 CI에서 바이트 단위로 재현된다.

**논의.** 본 프레임워크는 예측 시스템이 아니라 방법론 포스터이며, 본질적으로 허구·합성·비식별이다. 엔진은 정책 차원에서 국방·예측치안·PSYOP·비동의 트위닝·미성년 합성 파이프라인 사용을 거부한다. 감사 가능한 리플레이와 변수 3-tier 노출이 RAT 기반 시뮬레이션 연구의 투명성과 평가가능성을 높이는 실용적 경로임을 제시한다.

**키워드**: 일상활동이론; 에이전트 기반 모형; 감사 가능한 리플레이; 민감도 분석; 재현성; 합성 시나리오; 시민용 정책.
