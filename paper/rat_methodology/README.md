# RAT Methodology Paper Drafts (T4.5)

This directory holds the academic-output drafts for the realism roadmap's
T4 final-period track:

- ``kci_draft.md`` — Korean-language KCI submission draft (target: a Korean
  criminology / computational social science journal). Audience: domestic
  reviewers; tone follows KCI conventions.
- ``ssci_draft.md`` — English-language SSCI submission draft (or arXiv
  preprint). Audience: international computational-social-science
  reviewers; aligns with the ASC 2026 methodology poster.
- ``methodology_section.md`` — shared canonical methods section reused by
  both drafts. Single source of truth for the locked vs adjustable
  surface, the convergence rule, the Sobol sensitivity panel, the
  replay-hash invariants, and the Civilian Use Policy alignment.

These are **drafts**, not submitted manuscripts. Submission timing is
2027-09 for KCI and 2027-12 for SSCI per the realism roadmap §7.5
schedule. The drafts ship now so committee/peer review of the framing,
ethics boundary, and citation set can begin in parallel with the T2/T3
implementation tracks.

## Civilian Use Policy alignment

All three documents include an explicit `Civilian Use` paragraph linking
to ``POLICIES/civilian_use.md`` and disclaiming prediction, per-person
risk scoring, and operational deployment.
