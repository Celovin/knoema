\begin{abstract}
Knoema Engine is an open, MIT-licensed runtime for persistent social agents whose state is inspectable outside of a model prompt. The system combines persona definitions, short-term and long-term memory, directed relationship state, environment context, PAD-style emotion, optional persona-level theory-of-mind tracking, event scheduling, deterministic logs, and optional LLM-backed decisions. This report presents the Phase 30 arXiv-oriented technical draft, updated from the initial MVP report with a 50-agent deterministic village experiment, a formal benchmark bundle, a scenario DSL, game SDK facades, a deterministic Sally-Anne harness, and documentation surfaces. The central engineering claim is modest: persistent-agent applications need explicit runtime state, replayable artifacts, and adapter contracts before they need larger prompts. Knoema demonstrates this through three application tracks: game NPCs, synthetic replay research, and reproducible academic simulation. Public-safety examples are fictional, synthetic, and non-identifying; the system is not designed for prediction, suspect scoring, surveillance, or enforcement automation.
\end{abstract}
